# sistema_de_gestion
Sistema de Gestión de Clientes, Servicios y Reservas.

Este proyecto consiste en desarrollar un sistema de gestión de clientes, servicios y reservas.

El programa está desarrollado en Python y utiliza POO. Permite crear clientes, registrar diferentes tipos de servicios, realizar reservas y calcular sus costos. También incluye validaciones y manejo de excepciones para controlar errores durante la ejecución.
